# 方块矿洞 Implementation Plan

> 按用户的“帮我实现”授权在当前任务连续实施，使用 executing-plans 流程。

**Goal:** 增加完整可玩的单人挖矿游戏及大厅入口。
**Architecture:** core.js 提供纯数据规则，game.js 负责输入、Canvas 渲染和存档，CSS 负责自适应界面。
**Tech Stack:** 原生 HTML/CSS/JavaScript，Node assert 与已安装 Chrome 验证。
**Spec:** docs/superpowers/specs/2026-09-25-mine-design.md

## Global Constraints
无外部依赖、无登录、无金币；相对资源路径；自动存档失败不阻断游戏。

## Review Focus
损坏存档不能崩溃；水晶不能重复计数；边缘不能越界；小屏点击与画面坐标一致；暂停/弹窗时不能操作地图。
