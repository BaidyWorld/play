# 方块矿洞：寻宝归来

用户已认可聊天中的设计并要求实现。为现有静态小游戏大厅增加单人挖矿游戏，面向小学生，无登录、金币、付费或外部依赖。

## 游戏规则
横截面方格矿洞，方向键/WASD 在已挖通的相邻格移动，矿工自带攀爬绳，无重力陷阱。镐子挖相邻格：泥土一次、岩石两次、水晶三次；石块铺地下水为可通行桥；火把照亮通道。找到三颗水晶并回到地面营地获胜，无计时失败。地图显示已探索区域及目标层，背包显示材料。

## 界面
草图中的中央快速开始/继续游戏菜单、右侧说明、底部五格快捷栏保留。地面浅蓝天空和草地，地下棕色转蓝灰岩石，青色水晶。桌面双栏，手机单栏，触摸方向及行动按钮至少44px。支持键盘及减少动态效果设置。

## 数据与实现
新增 mine/index.html、mine/style.css、mine/core.js、mine/game.js；HTML/CSS/Canvas 原生实现，支持 file URL 及仓库子路径。矿洞编号确定随机地图；三颗水晶固定在不同深度且周围可挖，水可绕开。localStorage 自动保存每次有效操作，仅保留一个矿洞；新游戏替换存档前明确提示。存档损坏忽略，存储禁用仍可玩并提示。

## 验收
可通过正常移动挖掘完成三颗水晶收集并返回；同编号生成相同地图；不能隔空挖掘、穿墙、凭空搭桥或重复采集。刷新恢复状态。验证桌面/手机布局、实际按钮键盘触摸事件、菜单暂停、新局和地图背包、存档损坏、仓库子路径和原有游戏回归。
