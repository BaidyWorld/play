# 小小英语本

三年级上册英语点读与纸笔默写网页。词表从用户提供的三张教材照片录入，共 165 条：Unit 1–8 的单词、短语、句子，以及 3 条专有名词。单元中文名称是为了导航添加的主题提示。

## 使用

1. 选择单元，点击英文或喇叭听读；每条显示英式音标与中文。
2. 词表的长短词条字号一致，英文标签保持单行；按实际文字宽度扩大卡片，容器宽度、词表内容或字体加载发生变化时才重新计算；手机地址栏伸缩造成的高度变化不会重复重排卡片。跟读并在纸上写，可“遮住英文”自行回忆。
3. “开始纸笔听写”每组最多 5 条。底部先显示整行“播放录音”，点击后原位置变为“展开答案”，展开后显示“再练练／写对了”。需要重听可点击题目旁的“重听一遍”，或按空格。写完展开答案，再手动选择“写对了”或“再练练”。
4. 在“遮住英文”和发音状态右侧点“自动朗读”，按当前列表顺序逐条播放，跟随高亮与滚动，读完自动结束。“暂停朗读”后可继续，从当前词重新开始；“结束朗读”退出。筛选“再练词”后只读筛选结果；切换单元、音源或音色、手动点词、进入听写会结束自动朗读。教材音源每条仍保留原录音的两遍。
5. 星标保存为再练词。写对不会自动移除星标，可在词表中自行移出。

页面顶部的音源默认是“教材原声（双读）”，点击单词、短语或句子会播放教材中的两遍原声；听写空格重听、速记页点读也使用同一音源。用户提供的 Unit 1–8 录音已整理为 162 个点读片段。China、Thailand、UK 未包含在这批录音里，点读时会明确提示使用设备朗读。音源选择会保存到当前浏览器。进入课本时预加载当前单元的点读片段，进入听写或速记分组朗读时预加载该组录音；同一页面会去重请求。使用浏览器 HTTP 缓存，预加载失败时允许后续重试，不阻止点读和听写。首次进入仍需要下载音频。

切换“设备朗读”后，可以选择英式／美式发音、设备上的朗读角色并试听。Aaron、Eddy、Google US English 优先排列，其后是 Daniel、Samantha、Alex 等常用音色；手动选过的角色优先于排序。设备音色选择同样保留。初次设备朗读优先英式，只有美式时默认美式；手动指定口音后，缺少对应声音会明确提示。教材原声的口音与角色随原录音，不受设备音色影响。

U4 第 06 条按原声显示为“child / Children”，并列单复数音标；设备朗读同样会读 child、children。词条编号保持不变，原有星标与听写记录继续使用。

下方音标采用英式标注。短语和句子未展示所有连读与弱读变化。

进度仅保存在当前浏览器，换设备、清除浏览数据或使用隐私窗口会失去记录。核对结果由孩子或家长记录，网页不会识别纸上手写。

## 纸笔听写与快捷键

桌面上左侧听题、右侧展开答案与核对，答案区域提前预留空间。PC 顶部栏右侧、手机标题右上角的“朗读设置”首次默认收起，可一起展开／隐藏设置区和“听一听，写一写”介绍。手动开合状态保存到当前浏览器；所选单元或串词速记页面也会保存，刷新后恢复。听写进度不随刷新保留，刷新回到对应词表或速记页。手机进入听写时默认收起，听写顶部保留同一入口；听写模块按当前可见屏幕高度排布，播放、核对和切题按钮保持在屏内。长答案与本组结果可以在卡片内部滚动查看，页面不需要上下滑动。返回词表或速记页后恢复常规页面布局。

- 左右方向键：上一题／下一题，也有对应按钮。跳过的未核对题会在本组继续出现；全部核对后才显示结果。
- 空格：重听当前题目。
- 回车：依次播放录音、展开答案，展开后记为“写对了”并继续。按住按键不会连续记分；在音色选择框、搜索框等输入控件中保留原本键盘操作。
- 回看已核对题可以改判，同一轮的同一题不会重复增加练习次数。

## 串词速记

从左侧“专有名词”下方的“串词速记”菜单进入，手机上课程以四列网格完整显示，8 个单元占两行，“专有名词”“串词速记”并排在第三行，无需左右滑动。“串词速记”展示全册 165 条词汇，人工整理为 40 组，分为相似拼写与读音、对照与词形变化、场景联想。一个词可以出现在不同联想中，每组 2–8 条，记忆提示只描述这些词的关系，不作为通用拼读规则。

词汇字号与课本保持一致，长短词条同一字号、单行显示。每条附中英对照短例句，点击例句使用设备朗读（沿用所选口音和角色），不会修改教材音源选择；例句是本应用编写的练习内容。每组右上角的“朗读单词”只顺序读该模块当前可见的词，原按钮可暂停／继续，不使用浮动工具栏。切换组、搜索、点例句或单词、进入听写都会结束当前分组朗读。

支持中英文搜索、点击点读、星标、遮住英文与音标。“遮住英文”时也移除含英文拼写的记忆提示，同时隐藏含英文的例句，只保留中文释义与回忆任务。点击“练这一组”按当前分组进入每轮最多 5 条的纸笔听写，完成或返回后可回到速记页。

教材音频按“单元原文件 + 逐条双读片段”保存，参见 [音频整理说明](audio/textbook/README.md)。原文件保留完整内容；点读片段不包含单元报幕。

## 自然拼读着色

词表、展开后的答案和本轮回顾中，橙色提示元音，绿色下划线提示字母组合，灰色虚线提示本词中不单独发音的字母。遮词和未展开的听写题不会显示着色答案。“拼读着色”右侧可切换“取消着色／显示着色”，只改变现有字母的颜色，不重新创建卡片；开关保存到当前浏览器。

着色是针对本册词汇的拼读提示，不是音节划分，也不表示所有同色组合都发同一个音。复杂词和复合词包含人工修正；新增词库时需要复核例外。

字母组合参考英国教育部的 [自然拼读对应说明](https://www.gov.uk/government/publications/assessment-framework-for-the-development-of-the-year-1-phonics-screening-check/assessment-framework-for-the-development-of-the-year-1-phonics-screening-check)。

## 本地运行与验证

从仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:4173/english/ 。页面使用 ES modules，需要 HTTP 服务；不要直接双击 HTML 文件。

```sh
node --test english/tests/*.test.mjs
node check.cjs --deployment-only
```

无运行时第三方依赖，无需构建。`english/` 随整个仓库由 GitHub Pages 提供服务；词汇、音标均包含在本目录内，教材照片不随网页发布。顶部可返回游戏大厅。
