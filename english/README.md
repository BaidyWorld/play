# 小小英语本

三年级上册英语点读与纸笔默写网页。词表从用户提供的三张教材照片录入，共 165 条：Unit 1–8 的单词、短语、句子，以及 3 条专有名词。单元中文名称是为了导航添加的主题提示。

## 使用

1. 选择单元，点击英文或喇叭听读；每条显示英式音标与中文。
2. 跟读并在纸上写，可“遮住英文”自行回忆。
3. “开始纸笔听写”每组最多 5 条。写完展开答案，再手动选择“写对了”或“再练练”。
4. 星标保存为再练词。写对不会自动移除星标，可在词表中自行移出。

页面顶部可选择英式／美式发音、设备上的朗读角色，并点击“试听角色”。选择会保存在当前浏览器。Aaron、Eddy、Google US English 优先排列，其后是 Daniel、Samantha、Alex 等常用音色，其他声音保留设备原有顺序；自动选择也使用此顺序，手动选过的角色优先于排序。初次打开优先英式，只有美式时默认选美式；手动指定口音后，缺少对应声音时明确提示，不使用另一种口音替代。语音随系统和浏览器变化，不是教材原声。需要在孩子的真实设备上试听。短语和句子的音标按词典式读音排列，未展示所有连读与弱读变化。

进度仅保存在当前浏览器，换设备、清除浏览数据或使用隐私窗口会失去记录。核对结果由孩子或家长记录，网页不会识别纸上手写。

## 纸笔听写与快捷键

桌面上左侧听题、右侧展开答案与核对，答案区域提前预留空间；手机窄屏上下排列，展开前后卡片高度保持一致。长答案可以在答案区域内滚动查看。

- 左右方向键：上一题／下一题，也有对应按钮。跳过的未核对题会在本组继续出现；全部核对后才显示结果。
- 空格：重听当前题目。
- 回车：未展开时先展开答案，展开后记为“写对了”并继续。按住按键不会连续记分；在音色选择框、搜索框等输入控件中保留原本键盘操作。
- 回看已核对题可以改判，同一轮的同一题不会重复增加练习次数。

## 串词速记

“串词速记”展示全册 165 条词汇，人工整理为 40 组，分为相似拼写与读音、对照与词形变化、场景联想。一个词可以出现在不同联想中，每组 2–8 条，记忆提示只描述这些词的关系，不作为通用拼读规则。

支持中英文搜索、点击点读、星标、遮住英文与音标。“遮住英文”时也移除含英文拼写的记忆提示，只保留中文回忆任务。点击“练这一组”按当前分组进入每轮最多 5 条的纸笔听写，完成或返回后可回到速记页。

教材原声尚未收录；本轮访问世纪外语网返回 HTTP 405，未取得对应教材的音频文件。当前所有朗读仍使用设备语音。

## 自然拼读着色

词表、展开后的答案和本轮回顾中，橙色提示元音，绿色下划线提示字母组合，灰色虚线提示本词中不单独发音的字母。遮词和未展开的听写题不会显示着色答案。

着色是针对本册词汇的拼读提示，不是音节划分，也不表示所有同色组合都发同一个音。复杂词和复合词包含人工修正；新增词库时需要复核例外。

字母组合参考英国教育部的 [自然拼读对应说明](https://www.gov.uk/government/publications/assessment-framework-for-the-development-of-the-year-1-phonics-screening-check/assessment-framework-for-the-development-of-the-year-1-phonics-screening-check)。

## 本地运行与验证

从仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 http://127.0.0.1:4173/english/ 。页面使用 ES modules，需要 HTTP 服务；不要直接双击 HTML 文件。

```sh
node --test english/tests/*.test.mjs
node check.cjs --deployment-only
```

无运行时第三方依赖，无需构建。`english/` 随整个仓库由 GitHub Pages 提供服务；词汇、音标均包含在本目录内，教材照片不随网页发布。顶部可返回游戏大厅。
