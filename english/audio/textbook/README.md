# 教材原声（双读）

来源：用户从“上教英语”下载并提供的 `Unit1.mp3` 至 `Unit8.mp3`。

- `units/unit-01.mp3` 至 `unit-08.mp3`：8 个单元原文件，逐字节复制，SHA-256 记录于 `../../textbook-audio.mjs`。
- `words/u1-1.mp3` 等：162 条点读片段，与词库 ID 对应，每条保留教材的两遍朗读及中间停顿。原单元报幕和相邻词不包含在点读片段中。
- `../../textbook-audio.mjs`：每个片段的单元、起止秒数、路径、双读标记，以及原文件校验值。

`grandfather`、`grandmother` 点读片段保留主词两遍，随后单独朗读的 grandpa／grandma 留在完整单元录音中。`a / an`、`child / children`、`mouse / mice` 按原录音保留每组两遍。

China、Thailand、UK 未收录在这批音频中，网页会明确提示改用设备朗读。原声文件播放失败时会提示重试或切换音源，不把系统声音冒充为教材原声。

## 重新生成点读片段

需要 Node.js 与 FFmpeg，从仓库根目录运行：

```sh
node english/scripts/prepare-audio.mjs
```

脚本先校验全部单元原文件的哈希，再按时间索引生成片段并逐条解码验证。160 个片段直接保留原 MP3 音频帧；`u4-11`（can）和 `u4-12`（fun）之间仅约 23 毫秒停顿，使用精确重编码，避免帧边界带出相邻词。原文件始终不改动。

时间索引通过本地识别、静音区间与教材顺序交叉核对；识别容易合并重复句子时，另外核对两次单独朗读。此过程未进行人耳逐条试听。识别工具和模型不属于网页依赖，也不随项目发布。

教材音频的权利归原权利人；仓库的 Apache-2.0 许可不适用于本目录的教材音频。
